# University Network Infrastructure Project

## Overview
This repository contains the final Computer Networks project focused on designing and implementing a secure university network infrastructure using Cisco Packet Tracer.

The project demonstrates how enterprise-level networking technologies can be applied in an educational institution environment to provide secure, scalable, and manageable communication between departments.

---

## Project Features

- Department-based VLAN segmentation
- Inter-VLAN routing using multilayer switch
- Dynamic routing with EIGRP
- Site-to-site VPN using IPsec
- Firewall security using ACLs
- SNMP network monitoring
- LLDP device discovery
- SYSLOG centralized logging
- Network troubleshooting scenarios
- Quality of Service (QoS) planning

---

## Departments Included

- Rectorate
- Management
- Business School
- School of IT
- Research & Library
- Student Services
- Finance
- HR and Legal
- IT Department
- Server Room

---

## Network Technologies Used

| Technology | Purpose |
|---|---|
| VLANs | Network segmentation |
| Trunk Links | VLAN communication between switches |
| Inter-VLAN Routing | Communication between departments |
| EIGRP | Dynamic routing |
| ACLs | Firewall and traffic filtering |
| VPN IPsec | Secure remote communication |
| SNMP | Monitoring network devices |
| LLDP | Neighbor discovery |
| SYSLOG | Event logging |
| QoS | Traffic prioritization |
